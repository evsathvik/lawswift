# LawSwift – AI Legal Assistance & Document Intelligence Platform

LawSwift is an AI-powered LegalTech platform designed to simplify legal document analysis, risk detection, and agreement generation for users and small businesses.

## Features

- AI-powered legal document analysis
- Detection of harmful or risky clauses in agreements
- Legal risk flagging and clause highlighting
- Automated document generation
- Rental agreement generation
- Sale deed generation
- Freelancer-company contract generation
- AI-based clause recommendations
- User-friendly document workflows
- Responsive frontend interface

## Tech Stack

- ReactJS
- JavaScript
- Python
- Gemini API
- MySQL

## Project Overview

LawSwift helps users understand legal agreements more effectively by scanning documents and identifying potentially harmful or unfavorable clauses. The platform can also generate legal documents such as rental agreements, sale deeds, and freelancer contracts based on user requirements.

The system additionally recommends clauses that can be included in agreements depending on the specific needs and conditions provided by the user.

## AI Features
